## Negative checks to retain or add

For each function accepting a receipt, household product, correction, batch,
activity, or token identifier, exercise a second household with valid IDs from
the first. Require rejection or the documented null/false result and no writes,
scheduled work, or provider calls. Invitation joining is an explicit exception:
a valid invitation authorizes joining if the household has room.

Test image GET/POST through HTTP, including no session, another household,
invalid position, deletion between authorization and attachment, duplicate
uploads, and access after sign-out/session expiry. The existing imageAccess unit
checks do not alone prove HTTP identity forwarding. Test foreign web origins
through Better Auth routes as well as the configuration helper. Do not assert
that every public route needs a session: sign-in and public policy must remain
available before authentication.
