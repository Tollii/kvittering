# pr-media

Screenshots, GIFs, and videos linked from pull request descriptions. This branch never merges into `main` and has no shared history with it.

Add files under `<branch-name>/` and only append commits. Link to files by commit SHA so the links survive later pushes:

- Images and GIFs: `https://raw.githubusercontent.com/Tollii/kvittering/<sha>/<path>`
- MP4 videos: `https://cdn.jsdelivr.net/gh/Tollii/kvittering@<sha>/<path>`
